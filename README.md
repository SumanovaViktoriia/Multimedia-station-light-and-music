# Режимы светомузыки

```bash
source .venv/bin/activate
python3 music_led.py --mode <режим> --file трек.mp3
```

`--file` можно без `music/` — папка подставится сама.

Цвет от **ноты** (C = красный … B по кругу).

| Режим | Что делает |
|-------|------------|
| `center` | Пульс от центра; цвет = текущая нота |
| `strobe` | Вспышки цветом ноты |
| `rainbow` | Радуга со сдвигом от ноты |
| `fft_bands` | FFT: бас/mid/верх мягким градиентом (коралл → мята → лазурь) |
| `fft_dynamic` | Зеркальный heatmap: цвет (HSV) плывёт и теплеет от громкости бина |
| `fft_beat_pulse` | Club: heatmap + вспышка на удар баса (от центра) |

Чувствительность: `--sensitivity 10` (больше — сильнее реакция).
