# Светомузыка + туман

Лента WS2812B, диод на биты и парогенератор под музыку.

## Запуск

- Linux: `./run.sh`
- Windows: `run.bat` (можно двойным кликом)

Первый запуск сам ставит библиотеки. Ещё нужен `ffmpeg`
(`sudo apt install ffmpeg` / `winget install ffmpeg`).

Откроется меню треков из `music/`:

- `3` или `кукла` — играть трек (номер или часть названия)
- `3 center` — то же, но в режиме `center`
- `f` — фон вкл/выкл, `f flow` — сменить вид (`flow`, `rainbow`, `glow`, `off`)
- `b 0.3` — яркость фона, `v 2` — скорость переливов
- `p` — включить первый трек (при включённом `r` — случайный), `p r` — сразу случайный
- `r` — случайный порядок вкл/выкл, `a` — «после трека включать следующий» вкл/выкл
  (это переключатели, музыку сами не запускают)
- во время песни `q` или Enter — в меню (подсветка остаётся); если не трогать, после трека через `next_delay` секунд
  включится следующий (по кругу или случайный), в терминале пишется какой
- Ctrl+C в меню — выход из программы, всё гаснет (`q` в меню ничего не делает)

Сразу трек, без меню: `./run.sh кукла --mode rainbow`

Без скриптов: `python3 summary.py` (Linux) / `python summary.py` (Windows).

## Настройки

Всё в `settings.toml`: порт, число диодов, режим ленты, туман, фон.

Режимы ленты:

- `rainbow` — бегущая радуга
- `center` — пульс от центра
- `strobe` — вспышки
- `fft_bands` — бас / середина / верх
- `fft_dynamic` — спектр от центра к краям
- `fft_beat_pulse` — спектр + вспышка на бочку

Фон без музыки: `flow` (переливы), `rainbow`, `glow`, `off`.

## Пар

Кнопка парогенератора переключает его: нажали — включился, ещё раз — выключился.
На сильный бас плата нажимает кнопку, через `duration` секунд (`[fog]` в настройках)
сама нажимает ещё раз. Остановка трека и выход тоже выключают пар. Если плата
потеряла связь с ПК, она выключит пар сама.

Плата помнит, идёт ли пар (EEPROM), и после перезапуска выключит оставшийся.
Если включила или выключила парогенератор руками, в меню: `s` — «пар идёт, выключи»,
`s off` — «пар уже выключен».

## Arduino

Скетч `music_led/music_led.ino`, библиотека FastLED.
Лента — D6, диод — D5, реле — D7.
`MAX_LEDS` в скетче — сколько диодов на ленте физически.
